Problem Statement & Purpose

THE PROBLEM

  • Scattered academic records across multiple files
  • Inefficient grade tracking
  • Lack of centralized communication between staff and students
  • High administrative overhead

THE PURPOSE

  • One unified dashboard for all records
  • Automated grade calculations
  • Modern, responsive dark/light UI
  • Streamlined administrative workflows

Technology Stack

Backend

Python 3 Django SQLite 3

Robust ORM, secure authentication, and scalable app structure.

Frontend

HTML5 / CSS3 JavaScript (ES6) Chart.js

Custom design system, CSS variables for dark mode, interactive charts.

Key Features

  • Custom Dashboard: Rich analytics and dynamic charts.
  • Light / Dark Theme: Seamlessly toggles based on user preference using CSS custom properties.
  • Role-Based Access Control: Admin, Teacher, and Student profiles with distinct permissions.
  • Grade Management: Dynamic grading scale with visual indicators (e.g. A, B, C, D, F).

What Was Achieved

Successfully delivered a modern Student Management System tailored for academic institutions.

  • Clean, maintainable Django codebase.
  • Accessible UI with a bespoke design system (Editorial Slate).
  • Zero-dependency frontend styling architecture.

NEXT STEPS

Deployment to a cloud VPS, integration with email services, and mobile application development.
